# Süphan Grup Yapı Market - Dijital Katalog Portal

Mersin/Toroslar'da hizmet veren Süphan Grup Yapı Malzemeleri için hazırlanan, QR kod erişimli ve mobil odaklı dijital ürün kataloğu.

## Özellikler
- 📱 Mobil öncelikli (Responsive) şık e-ticaret arayüzü
- 💬 WhatsApp entegreli doğrudan fiyat/teklif isteme hattı
- 📍 Google Maps konum yönlendirmesi
- 🔍 Kategori ve ürün arama filtresi
- ⚡ Netlify üzerinde hızlı ve güvenli hosting

## Kullanılan Teknolojiler
- HTML5, CSS3, JavaScript
- Tailwind CSS / Custom Styling
